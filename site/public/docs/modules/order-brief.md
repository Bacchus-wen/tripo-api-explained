# Brief & Order / 需求与订单

- layer: create
- status: live
- tools: Astra

Turns a one-line request into an asset list in a single order JSON: objects, style, references, real-world size, face budget, targets and budget. Every downstream step follows the order.

把一句需求拆成资产清单，写成统一的订单 JSON：物体、风格、参考图、尺寸、面数上限、目标场景、预算。下游所有环节都按订单执行。

## Inputs
- A one-line request / 一句需求

## Outputs
- Order JSON / 订单 JSON

## QA
- Generation starts only after sign-off / 用户签字后才进入生成
