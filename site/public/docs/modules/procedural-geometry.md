# Procedural Geometry / 程序化几何

- layer: generate
- status: live
- tools: Blender Python, three.js

Tables, bases, belts and repeated parts are generated in code: precise, tweakable and free.

桌面、底座、传送带、重复构件这类规则几何直接用代码生成，精确、可调、不花生成费用。

## Inputs
- Floor-plan coordinates / 平面图坐标

## Outputs
- Mesh or glb / 网格或 glb

## QA
- Dimensions match the plan / 尺寸与平面图一致
